## Why

项目在 2026-04-05 执行了大规模代码清理后，仍存在一些无用文档和代码需要清理。本次清理旨在移除已失去上下文的文档、已完成的临时脚本、以及前后端分离后的遗留代码，保持代码库简洁。

## What Changes

- **删除过时文档**：移除与已废弃架构相关的文档（如旧版部署指南、不再适用的 API 文档）
- **删除临时脚本**：清理 `scripts/` 目录中用于一次性迁移/测试的脚本
- **删除残留代码**：移除前后端分离后遗留的未使用组件和工具函数
- **清理备份目录**：删除 `.cleanup-backup/` 目录（已有 Git 历史可追溯）

**影响范围**：
- 文档目录 (`*.md` 文件)
- 脚本目录 (`scripts/`)
- 备份目录 (`.cleanup-backup/`)

## Capabilities

### New Capabilities

无新增能力，纯清理任务。

### Modified Capabilities

无规范变更。

## Impact

- **无功能影响**：仅删除无用文件，不影响现有功能
- **构建影响**：构建速度可能略有提升（减少文件扫描）
- **Git 历史**：所有删除操作均有提交记录，可通过 Git 恢复
