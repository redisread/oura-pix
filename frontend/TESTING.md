# OuraPix 前端测试文档

## 本地测试步骤

### 1. 启动后端 API

```bash
cd /Users/victor/Desktop/project/github/oura-pix/api
pnpm dev
```

后端将在 `http://localhost:8787` 启动

### 2. 启动前端

```bash
cd /Users/victor/Desktop/project/github/oura-pix/frontend
pnpm dev
```

前端将在 `http://localhost:4321` 启动

### 3. 环境变量配置

确保 `frontend/.env` 包含：

```env
PUBLIC_API_URL=http://localhost:8787
```

## 故障排查

### 构建失败
```bash
# 清理缓存
rm -rf frontend/.astro
rm -rf frontend/dist

# 重新安装依赖
pnpm install

# 重新构建
pnpm --filter @oura-pix/frontend build
```

### API 连接失败
- 检查后端是否启动（localhost:8787）
- 检查 .env 中的 PUBLIC_API_URL
- 检查网络连接

### 登录问题
- 检查浏览器 cookie 设置
- 检查后端 session 配置
- 清除浏览器缓存重试
